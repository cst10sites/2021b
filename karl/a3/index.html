Tag Definition Example
<!DOCTYPE html> Defines the document type. This is an html document.
<title></title> Title of document that appears on the browser tab. See browser title above ("Assignment 3")
<p></p> A function that creates a block of text. This is a paragraph!
<h1></h1> A function that creates a header.

This is a header.
<a href="link">...</a> A function that creates a hyperlink. This is a hyperlink.
<img src="link" alt="image definition"> A function that creates an image.
<br> Creates a break in a line.
<hr> Creates a horizontal ruler.
<ul> <li>...</li> ... </ul> A function that creates an unordered list.
  • The list goes on...
  • ...
  • ...
<ol> <li>...</li> ... </ol> A function that creates an ordered list.
  1. The list goes on...
  2. ...
  3. ...
<table></table> A function that creates a table. This is a table.
<strong>...</strong> A function that makes text bold. This word is strong.
<sub>...</sub> A function that makes text align lower. This word is subbed.
<sup>...</sup> A function that makes text align higher. This word is supped.
